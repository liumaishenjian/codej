# 第一版前端验收指南

日期：2026-09-09。分支：`feat/tui-redesign`，起点 `main e51e6b5`。
这是重新设计的独立 React/Ink 前端。所有模型、搜索、Bash 和文件变更均为固定演示；
不会读取项目配置、执行命令、写文件或消耗模型额度。任意输入只用于展示消息与编辑交互，结果仍是固定示例。

## 启动

在任意 PowerShell 工作目录执行：

```powershell
npm.cmd --prefix 'G:\AI Cloud\cc-java-tui-redesign\cc-java-tui' run preview:tui
```

首次在其他机器检出需先在 `cc-java-tui` 执行 `npm ci`。
本机依赖已安装。不要使用旧目录的 `preview:rebuild`、`preview:design` 或 `codej --tui-rebuild` 进行本次验收；
这些入口属于此前工作树。本轮默认生产入口未切换。

## 推荐验收顺序

1. 启动后按 Enter：观察用户消息背景条、搜索分组、活动状态、输入上下边界。
2. 搜索约 2.5 秒后进入审批：完整命令、目录、说明和三项决策同时可见。
   ↑↓ 选择，Enter 确认；选本次允许或拒绝时，Tab 可编辑附加说明。
3. 允许后：Bash 输出原位更新；Ctrl+O 展开详细输出，再按一次收起。
   运行中可编辑正文草稿；Enter 不会另启一轮，草稿保持到演示结束。
4. 单选：数字直接选择并前进；也可 ↑↓ 后 Enter。第 4 项进入自由回答；
   输入中文或 emoji 后 Enter 保存。
5. 多选：数字或空格切换勾选，Enter 前进。Tab / Shift+Tab、左右键切题，答案保留。
6. 复核页：显示各题回答，Enter 才提交；漏题会返回缺失题，不伪装提交成功。
7. 回答结束：Ctrl+J 换行、←→/Home/End 编辑、退格/Delete 删除；
   空闲单行草稿用 ↑↓ 调出本次进程内输入历史。
8. 输入以下入口分别验收：`/bash` 命令、`/questions` 问卷、`/diff` 变更预览、
   `/error` 失败。输入 `/` 可见候选菜单。
9. Esc 在文本附加编辑中返回选项，在活动流程中停止；Ctrl+C 退出。
   PgUp/PgDn 回看，End 返回最新；`/clear` 清空演示。
10. 缩放到 80/120 列及 24/35 行；40 列检查折行。低于 40×24 时显示尺寸提示并暂停操作。

Shift+Tab 在普通输入区切换演示模式标签，不产生真实权限变化。

## 本轮实际验证

- 授权源与采用边界：[ADR-090](../adr/ADR-090-s15-terminal-experience-v1.md)。
- 新前端独立于旧 app、StdioClient 和 Java；未复制旧重构目录。
- Node v24.14.0：构建通过，18 个测试文件 / 309 项离线 TUI 测试全部通过。
  项目 Node 22 基线和 lockfile 未升级；未将 Node 24 结果称为 Node 22 兼容复验。
- 新增 7 项覆盖字素编辑、40/80/120 列面板、真实 Ink 键盘、审批反馈隔离与拒绝、
  多题单选/多选/自由回答/复核、漏题阻止提交、斜杠和 resize 草稿保留。
- 真实 Windows 伪终端完成：启动 → 搜索 → 允许 → 模拟输出 → 单选 → 多选 → 复核
  → 回答 → Ctrl+C，进程退出码 0，光标恢复序列可见。
- 伪终端由工具注入 NO_COLOR=1 / TERM=dumb，因此该检查只证明交互和生命周期。
  另用 FORCE_COLOR=3 的 Ink 输出渲染彩色图像检查布局；未宣称是物理终端截图。
- 人工看过搜索、审批、问卷和输出详览图；发现空白 Text 折叠导致间距丢失，已修正为显式空行。
  最后启用 Ink 已有增量刷新配置；不自行扩展私有渲染器。
- 完整测试日志：`target/tui-v1/full-tests.log`。本机渲染图片：
  `target/tui-v1/{idle,search,approval,question,review,command,done,error}.png`。
  这些属于忽略的生成物，不进入发布包。
