## 已知边界

- 50ms视图发布合并只减小密集更新频率，Runtime事件处理同步，审批/取消/断连/终态不等待。它不是增量Markdown解析或Agent调度器。
- 正常buffer只封存稳定前缀；当前回合可被finalText修正，因此超长未稳定回答仍保留可变尾部。完整最终正文进入原生历史，Ctrl+O使用当前会话记录。
- 同样式文字在绘制时合并，字素排版与光标保持独立；不新增ANSI解析器。
- 网页来源在支持终端上由OSC8承载（ADR-110），标签和完整地址保持可见；文件产物继续使用完整路径文本。物理点击、文件链接与详情鼠标仍待验证或实现。
- 本项目PTY、自动渲染和参考源码观察分别记证据；没有参考产品实机截图时不得声称视觉完全一致。Linux/macOS及复杂Provider质量不因本批通过提升等级。

### 2026-09-12 阅读方式补充（ADR-109）

详情页进入时固定记录范围，已有工具结果与审批仍实时；End查看新产生的记录，Ctrl+O返回。提交新任务取消旧范围限制，下一轮结果正常可见。窗口宽度变化复用有界Marked语法缓存。build、412/412（显式Java）、真实PTY展开审批/End最终回答/返回草稿/下一轮OK和看板通过；源码对照与失败修复记录见ADR109及核心证据。


### 文件修改验收补充（ADR-111）

在隔离目录分别创建和修改中文文件，确认批准前可见真实片段、批准后实际文件正确、最终回答可见；拒绝/取消仍无提前副作用。六尺寸检查长片段分页时审批选项固定。空内容、末尾换行、敏感内容、超长与旧宿主摘要须单独覆盖。整文件diff/参考实机仍是差距。


### 可靠交付验收补充（ADR-113）

增加验收失败带finalText、普通运行空结果、计划有说明但无审核、宿主主动取消、断连结果未知；说明正文必须可读，失败状态不能被正文覆盖。异常Ctrl+O只显示白名单诊断，正常聊天无流水；六尺寸检查输入仍可达。串联工具失败→解释→详情返回草稿→下一轮。


### 提交恢复验收（ADR-114）

增加空草稿/后续草稿下启动拒绝、只有protocol.error的兼容拒绝；计划确认及修改意见rejected后接protocol.error，原计划/编辑须保持且无自动重试；问卷返回复核仍保持原选择；旧审批错误不能覆盖新请求。accepted/queued后异常与取消不得生成可自动重发的原输入。


### 2026-09-13 问卷结果确认（ADR-115）

普通对话与/plan中提交问卷，确认发送等待期间无已回答历史；明确拒绝后修改答案并重提，工具成功后只有最后答案摘要。补充错调用/旧run、重复终态、工具失败、取消/断连、敏感结果、旧接口缺callId；模型收到原调用真实答案，下一轮可继续。


### 2026-09-13 工具到交付（ADR-116）

增加工具前说明→工具成功→空正文终态（必须提示缺交付）、任务更新不能替代回答；工具终态后重复start/output/结果及错callId不得覆盖原结果。普通计划内部调用隐藏，Ctrl+O可以核对参数/正文/失败/截断。配合三条真实入口路径及六尺寸回归。


### 2026-09-13 命令Shell契约（ADR-117）

ADR117：在用户任务不指定Shell的情况下，命令验证中文文件内容。核对模型生成方言、审批Shell、固定目录、实际输出、最终回答和下一轮。离线覆盖Local/WSL/Docker定义、禁止shell参数覆盖、读取定义不执行。


### 2026-09-13 文件审阅（ADR-118）

ADR118补充：中间行diff/多块上下文/多处替换；新建、删片段与末尾换行；六尺寸分页保留审批选择；敏感上下文/超限/无唯一匹配/路径逃逸不得伪造完整坐标。实际入口在审批期间外部修改文件，确认后必须冲突并保留外部内容；重新读取后正常修改与新建，核对磁盘、详情记录、最终回答和下一轮。

- ADR-119：验证文件工具终态摘要来自 Java 白名单元数据；敏感路径预览必须脱敏；失败不得显示成功文案；结果后可以继续下一轮。

- ADR-120：任务1必须覆盖正常写入、外部变化、删除、路径漂移、敏感/超限和失败终态；成功摘要必须来自 Java 核验元数据。

- ADR-122：任务2必须跑到计划描述、审核、确认、真实执行、核验、最终正文/产物和下一轮；真实跨进程 `real-java-plan-e2e` 6/6 通过后才可记录闭环。

  计划验证方式失败/恢复需保留终态通用解释，不能因隐藏内部工具而只留下计划正文；真实 Java→stdio→Ink 7/7 通过。

- ADR-123：演示层不得插入“更早内容／PgUp 回看”历史状态；普通滚屏由终端负责，详情阅读另行验证。

- ADR-124：长命令输出必须在摘要、展开、输入草稿和窗口变化下保持有界；验证缓存不跨流式记录复用，文件审阅超限仍显示摘要。

- ADR-125：真实 Provider 失败必须显示安全类别和建议动作；无效摘要不能进入普通对话；失败后可继续下一轮，不能显示成功正文。
- ADR-126：普通工具参数校验失败在活动回合显示已返回模型修正；终态没有宿主关联证据时只显示中性失败，不猜测后续调用已修正旧调用。
- ADR-127：运行中的长工具和当前回合长回答只排版有界尾窗，完成后恢复宿主有界正文；输入、审批和 Ctrl+O 阅读不因累计输出量失去响应。
